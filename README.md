# 🎮 遊戲庫網站模板 - 快速套用指南

這是一個現成的**遊戲分享網站模板**，專注於遊戲展示。如果你也想建立類似的網站，只需簡單幾個步驟即可快速部署。

## 🌟 模板特色
- 響應式設計（支援手機/電腦）
- 自動解析遊戲資料格式
- 背景圖片輪播系統
- 年齡驗證機制
- 遊戲搜尋功能
- 表單聯繫系統

## 📁 檔案結構說明
```
Game-Repository/
├── index.html              # 主頁面
├── windows.html            # Windows 遊戲頁面
├── android.html            # Android 遊戲頁面
├── style.css               # 基本樣式
├── Library/
│   ├── windows.txt         # Windows 遊戲資料
│   ├── android.txt         # Android 遊戲資料
│   ├── parser for windows.js  # Windows 解析器
│   └── parser for android.js  # Android 解析器
└── photo/                  # 圖片資源
```

## 🚀 快速套用步驟

### 1. 基本設定
- 下載所有檔案到你的網站空間
- 修改 `index.html` 中的網站標題、描述等資訊
- 更新 Google Analytics 追蹤碼（如需要）

### 2. 遊戲資料管理
**Windows 遊戲**：編輯 `Library/windows.txt`
```
###遊戲名稱###
##遊戲描述##
#v1.0下載(https://下載連結)#
@
```

**Android 遊戲**：編輯 `Library/android.txt`
格式與 Windows 相同，使用 `@` 分隔不同遊戲，最後一個項目也要寫，不然很浪費性能，因為沒有@他的解析就不會停

### 3. 圖片資源替換
- 背景圖片：替換 `photo/level/`（橫屏）和 `photo/upright/`（豎屏）中的圖片
- 確保圖片命名為 `001.jpg`、`002.jpg` 等三位數格式

### 4. 聯繫表單設定
修改 `Special for China.html` 和 `search.html` 中的表單收件信箱：
```javascript
this.action = "https://formsubmit.co/你的信箱@gmail.com";
```

### 5. 自訂樣式（可選）
修改 `style.css` 來調整顏色、字型等外觀設定

## ⚙️ 技術需求
- 靜態網站空間（GitHub Pages、Netlify 等均可）
- 支援 JavaScript 的現代瀏覽器
- 無需資料庫，純前端運作

## 📝 資料格式規範
遊戲資料使用簡單的標記語法：
- `###遊戲名稱###` - 遊戲標題（三顆#）
- `##遊戲描述##` - 遊戲說明（兩顆#）  
- `#v版本下載(URL)#` - 版本與下載連結
- `@` - 遊戲分隔符號，最後一個項目也要寫，不然很浪費性能，因為沒有@他的解析就不會停

## 🎯 客製化建議
- **遊戲分類**：可複製現有頁面建立更多分類
- **主題配色**：修改 CSS 中的顏色變數
- **背景系統**：可調整輪播時間或關閉自動輪播
- **搜尋功能**：目前支援遊戲名稱和描述搜尋

## ❓ 常見問題
**Q：如何新增遊戲分類？**
A：複製 `windows.html` 並修改檔案名稱、標題和對應的資料檔案即可。

**Q：可以改用其他網盤嗎？**
A：可以，只要修改資料檔中的下載連結格式，解析器支援任何 HTTP/HTTPS 連結。

**Q：如何關閉年齡驗證？**
A：刪除 `index.html` 中的年齡驗證彈窗相關程式碼即可。

**Q:能不能弄註冊帳號？**
A：不能，他只能讓你從0到1，上限就是1。
